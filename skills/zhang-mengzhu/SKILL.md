# 章盟主风格：大资金趋势

## 定位

核心问题不是：

“今天能不能涨停？”

而是：

> 哪个主线能够容纳大资金持续交易，哪个标的是主线中最具流动性和辨识度的趋势核心？

本 Skill 仅模拟市场常见的“大资金趋势”风格归纳，不代表章建平本人的交易方法。

与方新侠 Skill 的分工：本 Skill 看数周到数个季度的趋势核心，并检验产业和业绩逻辑；方新侠 Skill 只看 1–3 个交易日内的加速、分歧、回流节点。

## 资料边界

- 你不是章盟主本人，不得以第一人称冒充，不得编造他的观点、收益或仓位。
- 章建平从未公开阐述过交易方法。《中国经济周刊》2018年报道：“他的公开言论很少，也没有直接接受过媒体的采访”。网传“章盟主语录”和AI生成的风格总结都没有出处，不得引用。
- 可核验的足迹只有三类：
  1. 龙虎榜：国泰君安（2025年合并后为国泰海通）证券上海江苏路等营业部的归属来自媒体推断，营业部≠本人。龙虎榜只覆盖达到披露标准的个股和前五名营业部，并且在收盘后才公布。
  2. 前十大流通股东、举牌、定增公告：按季度或事件滞后披露，不是实时仓位。《中国经济周刊》2018年描述他在股东名单上的特点是“这个季度买入，下个季度就卖出，不多做停留”。
  3. 监管文书：证监会行政处罚决定书〔2024〕51号（2020年3月至2023年10月借用他人账户交易，罚款50万元）；上海证监局2019年2月1日警示函（海利生物持股达到披露比例后继续买入）。本 Skill 不输出任何类似的操作建议。
- 媒体对风格的描述：“尤好在权重大票主升浪上重仓出击”（界面新闻2021）。公开记录里，相关席位单日单票买入常见1亿至7亿元，多日合计曾达14亿至21亿元；也大额参与过连板人气股（如利欧股份、东方锆业）。筛选标准是流动性和成交额，而不是“是否连板”。
- 媒体估算的“浮盈XX亿”是用季末持股乘以之后的股价算出的，成本未知，不得当作已实现收益。

## 输入

每项数据都要标明时点：盘中 / 前一交易日盘后 / 季度滞后。

- 市场总成交额
- 板块成交额
- 个股成交额及在板块、全市场的排名
- 5/10/20 日均量
- 5/10/20 日趋势
- 主力净流入只能作为辅助：它是数据商按单笔金额估算的，各家口径不同
- 北向资金：2024年5月13日起不再公布实时成交额，个股持股改为按季度披露，不能用于盘中判断
- 机构数据：基金季报、前十大股东等，都是滞后数据
- 龙虎榜、大宗交易：收盘后披露，只用于盘后复盘和次日参考
- 公司基本面催化
- 产业趋势
- 政策催化

## 标的过滤

优先：

- 主线板块
- 高流动性
- 大成交额
- 市场辨识度高
- 趋势结构完整
- 有持续产业逻辑
- 能承载较大资金

降低优先级：

- 极低成交额小票
- 纯情绪末端补涨
- 连续一字无法正常换手
- 无板块支撑的独立脉冲

## 趋势阶段

识别：

底部放量 → 趋势建立 → 主升 → 加速 → 高位震荡 → 趋势破坏

只能用判断当时已有的数据命名阶段，并在输出里写明依据（例如均线排列、N日涨幅、成交额相对20日均额的倍数）；不得事后命名。

### 最佳研究区间

趋势建立至主升阶段。

### 风险最高区间

连续加速后的一致高潮。

公开记录中的例子：三安光电（2021年7月，相关席位三日买入约14.32亿元）、中科曙光（2023年4月，三日买入约20.83亿元）都发生在连续上涨后的高关注阶段，事后被媒体评价为接近阶段高点。大额买入不等于低风险。

## 模式 A：主线容量核心突破

条件：

- 板块处于主升
- 个股成交额位居板块前列
- 突破关键平台（写明平台的价格区间和形成天数）
- 放量但非异常爆量（写明成交额相对20日均额的倍数）
- 板块同步创新高

突破以收盘确认；盘中只能标为“待收盘确认”。

## 模式 B：趋势核心首次大分歧

检查：

- 中期趋势是否仍在
- 板块逻辑是否仍在
- 调整是否缩量
- 关键均线是否获得承接
- 回流时是否重新放量（只能作为次日确认条件，不能在分歧当天假设）

反例：浪潮信息2023-07-12发布上半年净利润同比下降60%—70%的业绩预告后跌停，相关席位当天净卖出超过8.4亿元，同日在人民网净买入1.85亿元。逻辑被证伪时，大分歧是退出信号，不是承接机会。

## MUST NOT

- 用小票连板思维评价容量趋势股。
- 因为没有涨停就判定弱。
- 因单日龙虎榜席位买入就追涨。
- 把“游资上榜”当作基本面。
- 把季报持仓当作实时仓位，或把营业部上榜当作本人操作。
- 引用无出处的语录。

## 风险

趋势失效重点：

- 板块成交持续萎缩
- 核心跌破趋势结构且无法收回
- 放量滞涨
- 产业逻辑证伪
- 同板块核心集体转弱
- 业绩预告、监管问询等事件风险
