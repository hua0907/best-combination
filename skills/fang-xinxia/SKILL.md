# 方新侠风格：容量趋势

## 定位

寻找：

> 主线 + 人气 + 容量 + 趋势 + 加速节点

不以连续涨停作为唯一强度标准。

与章盟主 Skill 的分工：本 Skill 只研究 1–3 个交易日内的关键节点；数周以上的趋势和基本面检验交给章盟主 Skill。

## 资料边界

- 你不是方新侠本人，不得以第一人称冒充，不得编造他的观点、收益或仓位。
- 方新侠的真实身份和年龄没有经过主流媒体披露，网传说法互相矛盾。
- 唯一可核验的足迹是龙虎榜：兴业证券陕西分公司（2020—2022年报道）、中信证券西安朱雀大街（2022年起）、国投证券西安曲江池南路（2025年，原安信证券）。营业部归属是媒体和社区推断，营业部≠本人；没有可核验的持仓和收益，网传“十大重仓股”只是上榜金额的汇总。
- 媒体描述（B/C级）：“操作上大开大合，极其擅长大成交趋势票”（证券时报2024）。
- 网传“精华留言”“心法语录”没有原帖链接；“香港方新侠”“国际游资教父”以及借用他名字的收费课程、荐股群都没有可核验依据，与本 Skill 无关。
- 公开记录里，其席位单日单票多在0.4亿至4亿元，常在1–3个交易日内买卖切换，甚至同日买卖。出手节点包括：
  - 涨停价大额买入：TCL科技，2024-04-01，中信证券西安朱雀大街以2.17亿元居买一，当日成交49.89亿元。
  - 加速日：利欧股份，2024-12-05，15个交易日内第10个涨停。
  - 跌停或大分歧日：中国医药，2022年3月18日买入2.86亿元、21日卖出1.46亿元、25日买入3.51亿元，4月1日在跌停价买入4.14亿元（后续结果未核实，不作为成功案例）。
- 龙虎榜收盘后才披露，只能看前一交易日。普通A股T+1；涨跌停时可能无法成交。

## 数据

需要（标明盘中或前一交易日）：

- 题材强度
- 板块成交额
- 个股成交额
- 个股市场成交排名
- 换手率
- 5/10/20 日均线
- 日K
- 分时
- 龙虎榜（只能看前一交易日：席位是否连续出现、是否同日买卖）
- 板块涨停结构
- 容量中军表现

## 候选池

只保留：

1. 当前主线
2. 成交活跃（成交额进入全市场或板块前列，写明排名）
3. 辨识度高
4. 趋势向上
5. 有板块联动
6. 回调有承接（写明依据，例如回调日的成交额和收盘位置相对关键均线）

## 三种模式

### 1. 趋势突破

平台整理后：

放量突破 + 板块共振 + 收盘维持强势。

“收盘维持强势”只能在收盘后确认；盘中只能标为“待收盘确认”。

### 2. 主升加速

趋势已经确认后出现：

成交增加 + 涨速提升 + 板块扩散。

注意：

连续加速不是新的低风险买点，越后期风险越高。公开记录显示其席位确实在加速段出手过，但龙虎榜数据无法判断这些交易的盈亏。

### 3. 强分歧承接

主线未结束情况下：

核心大幅分歧 → 成交释放 → 关键位置承接 → 板块回流。

“板块回流”只能作为次日确认条件，不能在分歧当天假设。

## 强弱判断

强：

- 分歧日抗跌
- 回流日领先
- 成交持续活跃
- 板块中军稳定

弱：

- 放量滞涨
- 每次板块回流都落后
- 跌破平台
- 高位出现连续长上影

## MUST

将“容量”与“龙头”分开判断。

一个股票可以是容量核心，但不是连板龙头。

区分“席位上榜”与“持续持有”：其公开足迹多为数日内的进出。

## MUST NOT

- 追逐低流动性后排
- 把一次大单买入当持续资金行为
- 只看龙虎榜不看趋势
- 忽略指数和板块流动性
- 把“方新侠席位买入”当作次日跟随信号
- 引用无出处语录或冒名内容
