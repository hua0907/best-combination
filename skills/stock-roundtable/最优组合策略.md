# 最优组合：五位辩手第一选择共识

> 2026-10-17 用户指定为“最优组合”。圆桌本身的裁决规则不变（9 位辩手各自选票，≥2 票为共识）；最优组合是在每场
> 收盘后 15:10 复盘的选票上另算的一条买入规则。

## 规则

| 项目 | 规则 |
|---|---|
| 成员 | 炒股养家、92科比、陈小群、赵老哥、乔帮主（5 位）。章盟主、方新侠、作手新一、瑞鹤仙的选票不看 |
| 用哪一场 | 只用收盘后 15:10 复盘。盘中 10:00 场不用（全部组合在 10:00 场几乎都亏） |
| 算哪张票 | 只算每位成员的第一选择，第二选择不算 |
| 买入条件 | 同一只股票被至少 2 位成员列为第一选择 |
| 买入时间 | 复盘的下一个交易日开盘买入；开盘一字涨停的排队，开板才成交，全天不开板就不买 |
| 仓位 | 每场复盘一份资金，几只同时符合就平分；没有符合的就空仓 |
| 卖出 | 买入后的下一个交易日（A 股 T+1）。回测按当天最高价和最低价的均价算；卖出日一字跌停卖不掉，按跌停价算 |
| 费用 | 回测未扣（来回约 0.1%） |

## 每天怎么用

1. 收盘后 15:10 以后，等 `D:\data` 里有了当天完整的 1 分钟文件，在本目录运行：

   ```
   python -X utf8 fetch_xdxr.py --refresh
   python -X utf8 run_backtest.py
   python -X utf8 optimal_combo.py
   ```

2. 打开 `output/optimal-combo/report.md`：第四节最后一行是最新一场复盘五位的第一选择和结论（“买入：…”或“空仓”），
   这一场用引擎重开、不看事后结果，并做防偷看审计。
3. 买入、卖出按上面的规则。逐笔结果和汇总在同一份报告里，每次运行都会更新。

## 为什么是它

- 9 位辩手的全部 511 个组合（单人、两两、三人……九人全体）× 全部票数门槛 × 只算第一选择/两张都算，共 4608 条规则，
  全部回测；另外试了每位辩手单独定算法的混合规则和“第一选择 2 分、第二选择 1 分”的加权票，合计 122706 条，
  10:00 场和 15:10 复盘各一遍。
- 在 511 个组合里它排第一：15:10 复盘 101 场（2026-05-15 至 10-13）合计 +166.30%，67 笔，每笔 +2.69%，胜率 63%，
  前段（05-15 至 08-10）+90.53%、后段（08-11 起）+75.77%。
- 挑选方法做过向前检验：7–10 月每月初只用当时已经结算的场次，在“至少 2 位同时选中”的组合里挑合计最高的一个，用到
  当月，69 场合计 +62.29%；同期圆桌现行规则 +17.99%，全部可选股 -12.57%。这个方法用截至 10-13 的全部数据，选出的
  就是这个组合。
- 前 20 名组合全都要求至少 2 位同时选中，其中 18 个只算第一选择；炒股养家、赵老哥在前 20 名里全部出现，92科比 90%、
  陈小群 85%、乔帮主 75%。
- 同样这五位，如果两张票都算，合计只有 +44.07%：“只算第一选择”是这条规则的关键。

## 风险和局限

- 它仍是事后排出来的第一名。把每场被提名股票的结果互相打乱（相当于谁选了哪只票不含信息）再挑，纯运气挑出的第一名
  中位数也有 +134%，约六分之一的情况超过 +166%。
- 回撤大：合计曲线最多从高点回落 31.8 个百分点。
- 数据只有 5 个月；选定之后的向前记录还很少（报告里标“选定后”的场次）。
- 卖出价按最高/最低的均价，是理想化的价格；回测未扣费用；`D:\data` 是 9 月下载的，5–9 月之间退市的股票不在里面。
- 建议先按这条规则逐日记录（纸面交易）一个月，再决定是否用真钱。
