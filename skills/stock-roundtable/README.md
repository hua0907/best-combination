# stock-roundtable 回测引擎说明

`SKILL.md` 讲用法和会议流程；本文件记录引擎的数据、口径和每位辩手的全部规则，方便逐条核对“Skill → 规则”的翻译。

## 对话窗口

- 接口（只监听 127.0.0.1，默认从 8840 端口开始找空闲端口）：`POST /api/send {text}` 提交一条指令（上一条没处理完时会拒绝）；`GET /api/messages?after=<id>` 取新消息和状态；`GET /api/state` 取当前会议、辩手和可选交易日。
- 消息：`role`（user / moderator / debater / system）、`speaker`、`kind`（选票/符合框架/有顾虑/不认可/中立/表态）、`group`（“完整材料”里的分组）、`blocks`（text / list / table）。
- 指令解析：绝对日期（`2026-09-24`、`20260924`、`9月24日`）或时点（`10:30`、`10点半`、`下午两点`、`收盘`）单独出现就是开会（`收盘`、`盘后` 和 15:00 以后的时间都是收盘后 15:10 复盘）；“最新、上一个交易日”等相对说法要带“开会”。股票按 6 位代码或名称识别，辩手按名字或别名识别。
- 某位辩手对任意一只股票的看法：自己选了的是“选票”；在他的候选里但不在他选的前两只里是“符合框架”；否则看他框架里的顾虑规则（“不认可”或“有顾虑”），都不匹配就是中立并说明他的框架看什么。这些只是看法，v2.0 起不影响共识票。
- “战绩”只用 `output/<模式>/nominations.csv` 里在开会日之前已经结算的选票：盘中会取日期早于开会日的，收盘后复盘取结算日（次日）早于开会日的；T+1 均价卖出只算卖出日早于开会日的。

## 数据

- 分钟线：`D:\data\<日期>.csv`，每只股票 240 根（09:31–11:30、13:01–15:00；15:00 那根含 14:57–15:00 的收盘集合竞价），成交量单位为手，成交额为元。
- 收完的交易日：至少 99% 的股票有 15:00 那根分钟线，而且当天北京时间已过 15:10（`config.CLOSE_BAR_SHARE`、`config.CLOSE_REVIEW`）。收盘后复盘、回测和事后结果只用收完的交易日：收盘后复盘在当天 15:10 之前或文件没收完时不开；回测遇到没收完的文件就停下；买入日或 T+1 卖出日还没收完时，相应的事后结果显示为待定。盘中会议照样可以用还没收完的当天文件。D:\data 里截至 2026-09-30 的全市场交易日，100% 的股票都有这根分钟线。
- 日线：youlong 的 `.catdesk-output\pit-cache-data24-t0ev035\_daily-raw`（只读），2025-04-07 起。
- 名称与通达信行业：youlong 的 `.catdesk-output\pit-cache-data20\universe.json`，2026-08-22 抓取的快照（只读）：5–8 月的决策用到的是之后的名称、ST 标记和行业，9 月下旬的决策用到的是一个月前的。
- 幸存者偏差：分钟线（04-30–09-18 于 2026-09-20 批量下载，09-21–09-24 于 09-24，09-28–09-30 于 10-03）和日线（09-24 抓取）都只含下载时仍在上市的股票，期间退市的股票整只缺失（日线面板 2025-04-07 起没有一只股票停止交易）。对 9 月下旬的决策影响很小（下载离交易只隔 0–3 天）；5–8 月的统计可能偏好看，缺的多是退市前持续下跌的弱股。
- 除权除息与流通股本：pytdx `get_xdxr_info`（youlong 已有部分 + 本目录 `cache/xdxr`）。
- 日线历史之后的 `D:\data` 交易日：由当天的分钟线合成日线（开、高、低、收、量、额），`D:\data` 一出现面板里没有的日期就自动重建面板。新上市、改名或新戴帽的股票在名称快照里可能缺失或过时。
- 没有成交的分钟线不算成交（v2.2 起）：TDX 给停牌股写入全天零成交的平线（D:\data 2026-09-18、09-24、10-09 起的部分文件，以及官方日线最近几天），不活跃的股票开盘前几分钟也可能是零成交的分钟线。规则：截止前没有一笔成交的股票不可见；全天没有成交的股票当天不进日线面板（停牌是空档：不打断连板、不进均值）；当天开盘价取第一笔成交那根分钟线，最高/最低从第一笔成交起算；次日开盘买入时停牌的不成交；T+1 卖出日停牌的不计入。v2.1 把这些平线当成交易日，影响的是有停牌股的那几天。
- 缓存：`cache/panel.npz`、`panel_meta.json`、`daily_raw.parquet`、`xdxr.parquet`、`market_<HHMM>.json`（盘面读数缓存按 `config.DATA_VERSION` 校验，只改选票或共识规则不会让它失效；日线面板记下了用来合成日线的分钟线文件大小，文件变了——例如收盘前取的文件换成了收盘后的完整文件——就重建面板）。删除后会自动重建（需要上面的只读输入）。
- 环境变量 `STOCK_ROUNDTABLE_ROOT` 可以把缓存和输出指到别的目录（例如用工作副本测试时复用已安装的缓存）。

## 防偷看口径

- 决策日 T 在面板中的行号为 t：历史只用 `[:t]`；T 当天只用开盘前已知的参考价（昨收，遇除权除息日用交易所规则算出的除权参考价）、涨跌幅档位和涨跌停价。
- 当日分钟线只用截止 bar 之前的部分；截止前没有任何成交的股票当作“还看不见”（按成交量判断：TDX 给停牌股写的零成交平线不算成交）。
- 历史价格按 T 当日的除权基准前复权；只用除权日 ≤ T 的事件。
- 流通股本只用日期 ≤ T 的记录。
- 收益在决策记录之后计算；收盘后复盘的结果要等第二天收完的数据读进来才结算；T+1 卖出读买入日之后那个交易日的日线，同样在决策记录之后才算。
- 审计：每隔 N 个决策日，把截止时点之后的全部日线、分钟线和股本数据换成随机数重跑，选票记录（每位辩手的选票、共识票的票数、名次和是否封板）必须完全一致。

## 涨跌幅与“板宽归一”

- 主板 10%；ST 主板 2026-07-06 前 5%、之后 10%；创业板/科创板 20%；北交所 30%；上市前5个交易日无涨跌幅限制（不进入可选池）。
- 涨停价 = round(参考价 × (1 + 档位))，按 youlong 的取整与容差判断是否在涨停价。
- 规则里的涨幅阈值统一按 10cm 口径折算（20cm 的 +10% 记为 +5），记录里显示的是原始涨幅。

## 市场与情绪

- 等权代理指数：可交易股票的等权日收益累乘；“站上5日/10日线”包含当日截止时点的值。
- 主线行业：按“触板家数×2 + 强势（≥5，10cm口径）家数 + 0.5×昨日涨停家数”排序，触板≥2 或强势≥4 的前3个行业。
- 联动簇：截止时点的强势股（≥5 或触板）按1分钟收益相关性做平均链接聚类（盘中阈值 0.6，收盘后复盘 0.5），≥3只成簇；簇按触板数排序，前两簇且触板≥3 也算主线。
- 龙头：行业内按“连板数（含今日封板）→ 是否封板 → 首次触板时间 → 成交额”排第一的非ST股；全市场最高板只看非ST股。
- 后排：在有≥2家触板的行业里，不是任何龙头/容量核心，且比行业首板晚30分钟以上才封板，或没封板且涨幅 <7。
- 情绪阶段（炒股养家用的市场通用分段）：触板数、跌停数、炸板率按前20个同口径交易日的分位判断（不足10天用固定阈值），再结合昨日涨停溢价与最高板变化，依次判定冰点→退潮→高潮→加速→分歧→修复→发酵，否则为混合。
- 92科比四阶段：最高板≥4 且不低于5日前、龙头封板或强势 → 主升；昨日涨停溢价 ≤ −2 或龙头大跌 → 主跌；最高板≥4 其余 → 高位震荡；否则低位震荡。

## 可选池

- 有涨跌幅档位、历史≥20个交易日、截止前有足够分钟线（盘中≥10根、收盘后复盘≥120根）；
- 截止时点成交额：10:00 ≥2000万，收盘后复盘≥8000万；其他时点按已过分钟数在两者间线性插值（10:00 以前按分钟数比例缩小）。辩手规则里的成交额门槛（章盟主、方新侠）用同样的插值，表中写的是 10:00 / 收盘两个锚点值；
- 盘中会议不选一字封死的股票；盘中共识票里已封涨停的照样排名，但只能按涨停价排队，之后开板才算成交。

顾虑一栏里的“硬”在对话窗口显示为“不认可”，“软”显示为“有顾虑”。v2.0 起它们只是辩手对别人选票的看法：不扣分、不淘汰，也不影响共识票。

## 共识票（v2.0 起的裁决）

- 每位辩手只按自己的框架选票：从自己的候选里按本框架的分数取前 `NOMINATIONS_PER_DEBATER` = 2 只（赵老哥板难做时 1 只；炒股养家在高潮、作手新一在观察/无主线、陈小群在无主线时不选），也可以一只都不选。辩手之间不互相投票、不质询、不答辩。
- 主持人只统计票数：被 `CONSENSUS_MIN` = 2 位及以上选中的是共识票，按票数从多到少排，同票数先比当第一选择的人数，再比成交额、代码。不设上限，不补位；没有共识票就空仓。
- 盘中会议已封涨停的共识票照样排名，注明只能按涨停价排队。
- 历史：v1.1 每场凑满 3 只；v1.2–v1.4 按“总分 = 得票 − 质疑扣分”取总分为正的最多 3 只，3 位及以上硬反对出局。v2.0 取消了质询、答辩、投票和扣分。

## 结果口径

- 盘中：截止那根分钟线（回测为 10:00）的收盘价买入；已封涨停的按涨停价排队，之后开板才算成交。
- 收盘后 15:10 复盘：次日第一笔成交那根分钟线的开盘价买入；开盘就在涨停价的按排队处理；次日没有成交（停牌）的记为未成交。
- 买入日（只看成交的）：买入时涨幅（相对前一日收盘）、收盘涨幅、收盘收益、买入后最高/最低、触板率、收盘封板率（y3）、买入后涨≥5%（板宽归一，y2）、胜率（收盘>买入价）。
- T+1 卖出：买入后的下一个交易日，按当天最高价（最佳）、高低均价（平均）、最低价（最差）卖出的收益（相对买入价，已扣除两天之间的除权除息影响，未扣交易费用），以及当天最高/最低/均价相对前一日收盘的涨幅。卖出日的数据还没有、还没收完或停牌的不计入 T+1 统计（组合里那一份按 0 计）。卖出日一字跌停（全天一个价且在跌停价）实际卖不掉：记 `t1_stuck`，收益仍按跌停价计入（与 study_t1.py 相同），每场记录和 summary.md 单独标出。
- 组合：每场一份资金，平分给这场的共识票（没成交的那份留作现金），没有共识票的会议算现金（收益为 0）；只统计 T+1 卖出日已有数据的会议。
- 旧版本的回测汇总存档在 `output/history/<版本>/`（`summary.md`、`audit.json`、两种模式的 `picks.csv`），换版本后可以前后对比；当前结果总在 `output/` 下。
