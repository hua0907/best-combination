# 作手新一风格：强势接力

## 定位

目标：

> 主线已经出现后，快速锁定最强、最有辨识度、最容易形成市场合力的核心。

不追求最低价格。

入场方式的优先顺序：热门强势股在分歧中的低吸 → 板上或突破确认。依据是他本人的帖子：“最好的交易策略还是有眼光护航的强势股低吸，一直和自己强调热门股的低吸”（淘股吧，2017-05-31）。

## 输入

分析：

- 新闻催化
- 政策/产业事件
- 板块涨停数量
- 连板梯队
- 竞价
- 分时
- 换手
- 成交额（判断容量）
- 封单
- 炸板次数
- 龙虎榜（盘后数据，只用于次日）
- 龙头与中军联动
- 市场和社区关注度

## 核心筛选

候选必须用判断当时可观察的信息回答：

- 为什么是这个板块？催化是否已经体现在板块涨停数和成交额上？
- 为什么是这只股票？辨识度、关注度、成交额哪一项领先？
- 和同板块第二名的差距在哪里？
- 入场方式是低吸还是板上确认？各自的触发条件是什么？
- 次日用哪些可观察条件验证（竞价强弱、开盘承接、板块涨停家数）？这一条必须在结论之前写下。

回答不了则降低等级。

## 模式 A：热门强势股低吸（首选，含龙头反包）

条件：

- 已经是主线或人气核心
- 分歧回落，但结构没有被破坏
- 回落过程中有承接
- 板块没有集体负反馈
- 反包时具有主动性、成交量合理

MUST NOT 把非主线股、弱势股的下跌当成低吸机会。

## 模式 B：核心突破接力

要求：

- 已有市场辨识度
- 突破关键价格，或主动买盘推动封板
- 成交充分
- 板块同步
- 非纯跟风拉升

MUST NOT 假设一定能按涨停价或一字板成交。

## 模式 C：分歧回封

检查：

炸板原因 → 承接 → 板块 → 回封主动性。

MUST NOT 看到回封就自动判定买点。

## 高位风险

以下组合出现时降低接力等级（本 Skill 的风险清单，不是他的原话）：

- 高位股连续大面
- 龙头天地板/准天地板
- 板块中军破位
- 后排批量掉队
- 连板晋级率快速下降

板块中军破位时，先判断龙头地位是否受损，不要只因为板块波动就处理绝对龙头。

## 仓位逻辑

策略权重跟随“证据充分程度”而不是“涨幅”调整。证据充分程度不等于上涨概率。

分档：

- 观察：只确认了主线
- 试错：主线确认 + 核心地位确认
- 标准：再加上情绪未退潮、承接或封单支持

每档都要写明失效条件和最大可承受亏损；弱市下调上限。他本人只说过“节奏是关键”；“讲究确定性”是媒体转述的网传说法（C级）。

## 退出

以下任何一项需要重新判断：

- 主线切换
- 龙头地位被替代
- 预期中的弱转强没有出现
- 分歧后无法修复
- 成交结构恶化
- 结论前写下的次日验证条件没有出现

板块或大盘的短时波动本身，不构成卖出绝对龙头的理由（参照转引的2017-06-10帖）。
