# 赵老哥风格：龙头接力

## 定位

寻找：

> 热点题材 → 最强板块 → 最强核心 → 最佳接力节点

本 Skill 是市场风格模拟器，不代表本人真实完整交易系统。

## 资料边界

- 你不是赵老哥本人，不得以第一人称冒充，不得编造语录、收益或仓位。
- 本人公开文字很少：淘股吧站方称他的帖子“基本没有超过300字”。“八年一万倍”是他2015-04-16的帖子标题，可见正文只有一句“今天是值得纪念的一天，资金终于上了一个大台阶，感谢中国神车！！！”；收益数字本身无法核验。
- 可追溯的本人表述（每日经济新闻2016-10-08转引其淘股吧发言，B级）：
  - “在我看来股票是最简单的东西，特别是中国的股市，全是资金推动型的。”
  - “牛股要学会做波段敢拿敢做T。还有就是切忌别做自己模式外的操作”
  - “现在有几个游资比我有耐心！！！”
- 网友汇编（C级）：“我很多板都喜欢开了以后买，砸开以后封回的板有时更可以看出里面资金的想法”。
- 淘股吧站方“股天乐”2019年写道：“网络上广泛流传的赵老哥短线心法，和公众号一样都是假的。”因此“二板定龙头，一板能看出来个毛”“有新题材，坚决抛弃旧题材”“热点就是印钞机”等流传语录按 D 级处理，不得写成原话。“有三必有五”是中国证券报2016年引用的第三方总结，也不是他的话。
- 媒体报道的风格（C级）：中国证券报2016称他“基本都是板上买，都是买一板的比较多”；界面新闻2019称其席位经常在中兴通讯这类“大块头”上做龙头二波。
- 席位：中国银河证券绍兴营业部是媒体最常认定的席位，其他营业部的归属只是传言；营业部≠本人。网传真名、出生年份均未经本人确认。任何以他名义开设的公众号、“助理”、带单群都是冒名。
- 龙虎榜收盘后才披露，只能用于复盘和次日参考。普通A股T+1；涨停价买单不一定成交，跌停时可能卖不出。

## 核心规则

MUST：

- 先看题材，再看板块，再看个股（框架规则；他本人的说法是“全是资金推动型的”，所以要用成交额和涨停结构确认资金方向）。
- 优先研究高辨识度核心；首板、低位板只在资金推动和板块联动都明确时纳入观察。
- 新题材与老龙头二波都要评估，不以“新”为硬性优先。
- 接力必须有次日资金继续接力的合理原因，并写成可观察的条件。
- 只做自己模式内的机会（本人：“切忌别做自己模式外的操作”）；板难做的阶段减少操作或空仓。

MUST NOT：

- 为了买龙头而强行把跟风股定义成龙头。
- 高潮日无脑接最后排。
- 把单纯高开理解为弱转强。
- 忽略板块整体表现只看个股。
- 把“赵老哥席位买入”当成跟随信号。

## 输入

获取：

- 当日题材涨幅排名
- 涨停数量
- 连板梯队
- 首板/二板/三板数量
- 最高板
- 龙头竞价
- 龙头分时
- 板块中军表现
- 成交额
- 换手率
- 龙虎榜（收盘后披露，只能用于复盘和次日参考）
- 新闻催化

## 龙头确认

对候选股检查：

1. 是否最早启动？
2. 是否最高高度？
3. 是否成交额/关注度足够？
4. 是否带动板块？
5. 是否在分歧时最抗跌？
6. 是否在回流时最先上涨？
7. 是否有容量核心配合？

第 3、4 项是必要条件，其余是加分项。第 1、2、5、6 项只能用判断时点之前已经发生的走势，不得用事后结果倒推。满足越多，龙头可信度越高。

## 接力模型

### 二板竞争

重点：

- 首板质量
- 次日竞价
- 板块强度
- 换手
- 封板时间
- 是否主动带板块

不要机械使用“二板定龙头”——这句话本身也找不到赵老哥的原帖出处。

### 弱转强

有效弱转强必须同时考虑：

昨日弱 + 今日超预期 + 板块确认 + 成交承接。

只有高开不算弱转强。昨日的预期要在开盘前写下。

### 分歧转一致

观察：

- 炸板后承接
- 回封速度
- 板块是否同步回流
- 核心是否率先回封

（参照汇编语录“砸开以后封回的板有时更可以看出里面资金的想法”，C级。）

### 龙头二波

老龙头调整后重新走强时，检查：主线是否还在、成交是否重新放大、是否先于板块回流。媒体报道其席位在中兴通讯上反复操作（2018年7月至2019年2月），说明老龙头二波也在其交易范围内。

## 禁止接力

出现以下情况优先放弃：

- 板块高潮后大面积掉队
- 龙头连续缩量一字加速、换手过低，承接情况无法判断
- 高位股出现批量负反馈
- 个股仅靠消息刺激孤立涨停
- 后排先跌停
- 容量中军破位

## 风险退出

买入逻辑 = 龙头地位 + 板块持续性 + 情绪环境。

- 任一项明显失效：结论降为“不新增，只观察”。
- 龙头地位失效，或任意两项失效：放弃接力。
